# TypeScript

- `strict: true`.
- Evitar `any`, `@ts-ignore` e casts duplos.
- Tipos compartilhados representam contratos, não espelham automaticamente tabelas.
- Validar dados externos em runtime com Zod.
- Não usar `number` para dinheiro sem decisão explícita sobre precisão/arredondamento.
- Preferir unions discriminadas para estados e resultados.
